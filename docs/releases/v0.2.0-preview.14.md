# Winlux v0.2.0-preview.14 — Terminal intégré

- Le terminal xterm est désormais un composant obligatoire de l’image système,
  avec ses bibliothèques et les descriptions terminfo xterm/256 couleurs.
- Lanceur commun `winlux-terminal` : Bash interactif, police DejaVu Sans Mono
  anticrénelée, UTF-8, fond sombre et historique de défilement.
- Le menu Démarrer utilise `shell:terminal`, comme Explorer. Son action
  **Ouvrir dans le terminal** conserve le dossier courant.
- Les `.exe` console lancés par double-clic utilisent ce même terminal,
  permettant de lire leur sortie et de saisir au clavier.
- Les applications Linux disposent aussi de `x-terminal-emulator -e commande`.
- La construction GitHub installe les prérequis ; une construction locale
  sans xterm échoue explicitement au lieu de produire un bouton sans terminal.

Mise à jour système complète et redémarrage nécessaires. Pour construire sans
installer xterm sur l’hôte, fournir `WINLUX_XTERM=/chemin/usr/bin/xterm` et
`WINLUX_TERMINAL_SUPPORT=/chemin` vers un paquet et ses bibliothèques extraits.

Le diagnostic de l’ISO ouvre réellement xterm sous Xvfb, vérifie les trois
descripteurs attachés au pseudo-terminal, le mode 256 couleurs, le dossier
contenant des espaces, l’exécution d’une commande et celle d’un `.exe` console.
