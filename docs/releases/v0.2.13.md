# Winlux v0.2.13

Mise à jour installable depuis Paramètres > Mises à jour sur une
installation v0.2.12, sans réinstallation. Une installation v0.2.6 ou plus
ancienne doit être réinstallée une fois avec l’ISO.

## ISO live et installation

- Le raccourci « Installer Winlux » démarre de nouveau l’installateur
  (il dépendait d’un outil absent de l’image).
- L’installateur ne plante plus au lancement : ses modules étaient absents
  de l’image.
- Réseau dans les machines virtuelles : la carte filaire est gérée et les
  serveurs DNS reçus par DHCP sont utilisés, au lieu d’une adresse figée qui
  ne fonctionnait que dans QEMU. Le secours réseau rallume aussi une carte
  éteinte.

## Mises à jour

- Si une version publiée ne fournit pas son fichier de description, la
  recherche de mise à jour lit directement la version sur GitHub (paquet,
  taille et empreinte de sécurité) au lieu d’échouer.
- Sans réseau, le message le dit clairement (adresse introuvable, délai
  dépassé…).
- Chaque version est testée avant publication : la version précédente est
  installée dans une machine virtuelle puis mise à jour depuis Paramètres.

## Système

- Changement rapide d’utilisateur : le deuxième compte ouvre maintenant
  son vrai bureau, sur son propre écran (#119).
- Impression : le service CUPS démarre avec la session.
- Son : PipeWire, avec un volume par application.
- Lecteurs réseau SMB et NFS par le noyau (modules embarqués).

## Compatibilité .exe

- WIC, Direct2D, DirectWrite et exceptions C++ MSVC maison : les
  applications C++ compilées avec /MD ne s’arrêtent plus à leur première
  exception (#191).
