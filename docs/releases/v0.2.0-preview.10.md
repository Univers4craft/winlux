# Winlux v0.2.0-preview.10 — menus contextuels du bureau

- Clic droit sur Explorer ou Paramètres dans la barre : ouvrir/afficher,
  épingler/désépingler, créer/retirer le raccourci du bureau, réduire et fermer.
- Clic droit sur les deux applications dans Démarrer pour les réépingler.
- Les applications ouvertes restent dans la barre après désépinglage et
  disparaissent à la fermeture ; les zones cliquables suivent le nouvel ordre.
- Raccourcis de bureau fonctionnels et déplaçables pour Explorer et Paramètres.
- Épingles et présence des raccourcis conservées dans le profil utilisateur
  (`C:\.local\share\winlux\taskbar.dat`). Les positions ne sont pas sauvegardées.
- Menu borné à l'écran, survol, fermeture par clic extérieur ou Échap,
  navigation par flèches et activation par Entrée.
- Après une installation réussie nécessitant un redémarrage, la page des mises
  à jour remplace ses actions par un bouton unique « Redémarrer pour terminer
  la mise à jour ». Les anciennes zones d'action ne restent pas cliquables.
- L'indicateur persistant pending-reboot reste exposé au bureau même si le
  fichier temporaire update-action a disparu.

Tests du vrai routage des clics inclus dans explorer_regression.exe ; clics X11
et rechargement d'un profil temporaire vérifiés en 1920×1080.
Le catalogue et les fenêtres des applications externes ne sont pas encore gérés
par cette barre des tâches ; ce menu concerne les applications intégrées.
Les versions Windows de Claude et ChatGPT ne sont pas encore exécutables :
voir le relevé des blocages dans docs/CLAUDE-CHATGPT-WINDOWS.md.

Mise à jour système sans remplacement du noyau ni des modules. Redémarrer après
installation pour charger le nouveau bureau. Aucun token dans les livrables.
