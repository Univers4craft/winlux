# Winlux v0.2.0-preview.8 — affichage du fond d'écran

- Corrige le fond d'écran absent : les images dépassant la limite d'une requête
  X11 sont envoyées par bandes au lieu d'être ignorées.
- Encode directement les couleurs des photos sur les écrans TrueColor pour
  éviter un échange avec le serveur X pour chaque couleur.
- Ajoute un test X11 réel de grande image en 1920×1080, exécuté en CI.

Paquet limité au runtime et à l'outil de mise à jour. Le noyau, les pilotes,
le bureau PE et les données personnelles restent ceux de l'installation.
Sur la VM en version 7, l'image de fond est déjà installée : ce paquet corrige
son affichage. Redémarrer la session ou la VM après installation.

Aucune nouvelle ISO n'est fournie pour ce correctif. La dernière ISO complète
est celle de la version 7 ; appliquer ensuite cette mise à jour.
La validation visuelle complète en 1440p et 4K reste à réaliser.
