# Winlux v0.2.12

Première version sur la base APT native. Les tags v0.2.7 à v0.2.11
n’ont produit aucune release (noms de paquets d’Ubuntu 26.04, préparation
de la base dans la VM de construction, bureau bloqué au démarrage sur un PC
sans Bluetooth, ISO au-delà de la limite de 2 Gio de GitHub, machine de
construction sans assez de disque) : cette version les remplace. L’installation sur disque, cassée par le nouveau
menu de démarrage, et un blocage d’écran du bureau à distance sont aussi
corrigés.

## Réinstallation nécessaire depuis v0.2.6

Le système de base passe à Ubuntu 26.04 LTS avec APT et dpkg natifs.
Une installation v0.2.6 ne peut pas être convertie en place : son outil de
mise à jour l’indique et propose de réinstaller avec la nouvelle ISO.
À partir de cette version, les mises à jour suivantes arrivent sous forme
de paquet `winlux-desktop` (.deb) installé par APT, sans réinstallation.

## Système

- Base Ubuntu 26.04 LTS avec APT natif, compatibilité systemd (`systemctl`)
  pour les paquets qui l’attendent (#38).
- Détection et configuration automatique du matériel (#61).
- Écran bleu d’erreur, journalisation centralisée et restauration du
  système (#69).
- Écran de connexion, invite d’élévation et arrêt/redémarrage propres
  (#42, #44).
- Mise à jour en place protégée : point de restauration, vérification
  après installation et retour automatique en cas d’échec (#151).
- Historique des fichiers, plusieurs utilisateurs connectés en même temps
  et bureau à distance (#119).
- Impression complète : CUPS, imprimer en PDF, boîte d’impression façon
  Windows 11 et page Paramètres (#111).
- Correctif : le bureau ne reste plus bloqué au démarrage sur un PC sans
  adaptateur Bluetooth (#142).

## Compatibilité .exe

- Runtime .NET intégré : les applications .NET s’exécutent sur le CLR
  Winlux, sans dotnet ni Mono (#73).
- Traduction Direct3D 11 vers OpenGL (#70).
- Direct3D 9 et 12, backend Vulkan et décodage vidéo matériel DXVA2,
  réglages dans Paramètres > Graphismes (#127).
- msiexec intégré : les installateurs .msi fonctionnent, et le Store
  propose le catalogue Windows Scoop Extras (#129).
- Applications .NET autonomes : quand l’application embarque son propre
  runtime, Winlux le démarre directement (#133, #143).
- WinSock complet pour le réseau des applications (#66).
- Son des applications Windows : waveOut, DirectSound, WASAPI et XAudio2
  (#115).
- Manettes (XInput/DirectInput), webcam (Media Foundation), micro
  (waveIn) et Bluetooth pour les applications (#114).
- Registre, COM et OLE (#65).
- Registre Windows partagé entre applications : chaînes Unicode, HKCR,
  fichiers .reg, reg.exe et regedit /s (#166).
- Presse-papiers commun entre applications Windows et Linux (#161).
- Lancement croisé Linux ↔ Windows : tubes, PATH, .desktop, protocoles et
  chemins convertis (#167).
- DLL libgcc/libstdc++ et vrais NtCreateFile/NtOpenFile (#71).
- Exceptions structurées (SEH), locales, services Windows et TLS (#63).
- Applications Electron (Claude, ChatGPT) et paint.net (#52).
