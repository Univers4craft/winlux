# Winlux v0.2.0-preview.5 — Audit documentation et durcissement de l'installation

## Audit des listes Markdown

- Réconciliation des cases cochées/non cochées de TODO.md, ROADMAP-SSD.md,
  INTERFACE.md, COMPATIBILITY.md, README.md et theme/README.md avec le code
  réel et les validations disponibles.
- Distinction explicite entre ce qui est réalisé, partiel, simulé ou non
  validé. Aucun code fonctionnel ni numéro de version n'est modifié par
  l'audit.
- Rapport détaillé dans docs/AUDIT-MARKDOWN.md.

## Durcissement de l'installation sur disque

- Installation hors ligne complète sur disque virtuel : GPT, BIOS et ESP,
  confirmation et refus des cibles dangereuses.
- Disque installé démarrant sans ISO en BIOS et UEFI, avec marqueurs PE
  séquentiels/parallèles, X11 et résultat global réussis.
- Paquet système et ISO complète construits localement ; BUILD-INFO indique
  le commit courant et les sources suivies propres.

## Audio et codecs

- Décodage MP3/AAC natif borné, tests de vrais fichiers mono/stéréo, bornes
  PCM, concurrence et PlaySoundA/W vers ALSA null ; étapes obligatoires de CI.

## Bureau et graphismes

- Deux fenêtres internes, trois icônes statiques, positions recalées sur
  grille, épingles fixes, recherche Démarrer non fonctionnelle.
- Double tampon pixmap X11, commandes GDI conservées, tests DIB.

## Qualité et livraison

- CI de référence verte : hygiène, tests unitaires/audio, PE séquentiels et
  parallèles, intégration, MinGW.
- rustfmt et Clippy propres sur Rust 1.99.

## Limites importantes

Le bureau reste expérimental : pas de vrai bureau vide configurable, pas de
catalogue dynamique d'applications, pas de positions persistantes utilisateur.
L'installation réelle sur hôte et le double-clic GNOME/KDE/XFCE ne sont pas
prouvés par cet audit. Matériel physique, Secure Boot et A/B non validés.
Winlux reste expérimental et ne garantit pas l'exécution de tout logiciel
Windows. Aucun jeton n'est inclus dans les sources ni dans le paquet publié.
