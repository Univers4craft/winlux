# Winlux v0.2.14

## Mise à jour

Une installation v0.2.13 se met à jour depuis Paramètres > Mises à jour,
sans réinstallation. Ce chemin est testé en machine virtuelle avant la
publication. Une installation v0.2.12 ou plus ancienne doit être
réinstallée une fois avec cette ISO (voir les notes de la v0.2.13).

## Sécurité : le bureau ne tourne plus en root

- Sur un système installé, le bureau et les programmes .exe tournent sous
  le compte créé à l'installation, et non plus en root (#258).
- Seuls les services système restent en root. Les actions
  d'administrateur passent par la fenêtre de contrôle de compte (UAC).
- Sans connexion automatique, la session s'ouvre sur l'écran de
  verrouillage. La session Live reste en root, comme sur une clé
  d'essai.

## Démarrage plus rapide

- Le menu GRUB d'un système installé est caché 1 s : Échap ou Maj
  l'affiche. Il reste visible 5 s quand Windows est aussi proposé. Le
  noyau démarre en silence (#254).
- Seul l'écran est détecté avant l'affichage. Le reste du matériel, les
  services, le catalogue du menu Démarrer et les raccourcis du Bureau se
  préparent pendant ou après l'apparition du bureau (#254, #259, #260).
- Xorg démarre plus vite dans les machines virtuelles sans 3D (#259).
- Les logiciels choisis dans l'installateur s'installent après
  l'arrivée du bureau, en basse priorité, avec une notification au début
  et à la fin. Avant, le premier démarrage durait près de deux minutes,
  sans aucun message.

## Claude Code dans Winlux

- La version Windows officielle de Claude Code (claude.exe) tourne par
  la couche PE de Winlux, sans Wine ni configuration (#255).
- Au premier lancement de l'entrée « Claude Code » du menu Démarrer, le
  programme est téléchargé et sa somme SHA-256 est vérifiée. Il s'ouvre
  ensuite directement dans le terminal Winlux (#257).
- La commande `winlux-claude-code` sert de secours (#256).
- Le moteur .exe gagne au passage : tubes nommés, console Windows
  complète, réseau, fichiers et identifiants Windows.

## Langues

- Les applications Ubuntu sont traduites en français, anglais, espagnol
  et allemand : menu de l'icône réseau, boîtes de dialogue GTK et
  PolicyKit, etc. (#253).

## Tests

- Les tests en machine virtuelle sélectionnent de façon fiable l'entrée
  diagnostic du menu GRUB, malgré son attente d'une seconde (#261).
