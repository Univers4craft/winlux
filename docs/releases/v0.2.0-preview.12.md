# Winlux v0.2.0-preview.12 — Bonjour.exe et qualité du rendu

- Corrige les programmes console lancés depuis Explorer lorsque le bureau
  hérite de la console de démarrage : ce terminal invisible ne sert plus de
  destination à leur sortie. Sans terminal installé, une boîte présente la
  sortie et son code de fin, et le journal est conservé.
- Le Bonjour.exe récupéré dans la VM a été testé : programme console x86-64,
  message « Bonjour depuis un .exe Windows… », fin normale avec code 0.
- Rendu anticrénelé Cairo des ellipses et diagonales, conservant les dessins
  actuels des icônes. LineTo utilise désormais la plume au lieu d'un cadre.
- Police DejaVu Sans explicitement fournie par l'ISO, utilisée aussi pour les
  mesures de texte.
- Redimensionnement GDI bilinéaire et cache d'image inchangée ; les bitmaps
  Full HD et 4K passent la limite mémoire contrôlée (16 Mégapixels).
- Cairo et ses bibliothèques sont intégrés dans l'image et dans les prérequis
  GitHub de construction. Pas de composant Wine.

Tests : sortie console avec pseudo-terminal hérité, PE, contours X11 avec
pixels de couverture intermédiaires, agrandissement 4K, captures natives de
1920×1080 et 3840×2160. Le fond source de 1672×941 reste limité en détails ;
le flou éventuel ajouté par le zoom du client VM n'est pas mesuré ici.
La comparaison avec Cinnamon porte sur sa pile graphique documentée ; aucune
VM Linux Mint n'a été démarrée pour un benchmark dans cette vérification.

Mise à jour système sans remplacement du noyau/modules. Redémarrer après
installation pour charger le runtime et le bureau mis à jour.
