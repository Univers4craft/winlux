# Winlux v0.2.0-preview.11 — lancement et réglages des exécutables

Cette publication regroupe les ajouts de la version 10, non publiée : menus
contextuels de la barre des tâches, raccourcis et bouton unique de redémarrage
après une mise à jour. Voir également les notes de la version 10.

- Un programme console compatible n'est plus refusé lorsque le terminal est
  absent : il s'exécute sans entrée interactive, avec sortie et code de fin
  présentés dans une boîte de dialogue quand disponible et enregistrés dans
  `~/.local/state/winlux/last-launch.log` (ou XDG_STATE_HOME).
- L'ISO embarque xmessage lorsque présent sur l'hôte de construction, pour
  rendre visibles les erreurs de lancement. Un vrai terminal reste nécessaire
  aux applications console interactives.
- Clic droit sur un fichier .exe dans Explorer : « Réglages de l'exécutable ».
  Renommer, supprimer et les autres actions restent accessibles.
- Réglages facultatifs : échelle automatique/100/125/150/200 %, diagnostic,
  enregistrer, restaurer les valeurs par défaut et lancer.
- Profil propre au programme dans `programme.exe.winlux.ini`, jamais interprété
  comme un script. Les valeurs inconnues sont ignorées et la lecture est bornée.
- Enregistrement explicite et message si le dossier du programme est protégé.
  Aucun réglage n'est requis avant un double-clic.

L'échelle règle le rendu Winlux, pas la qualité 3D interne d'un jeu. Ces options
ne fournissent pas les API Windows manquantes. Les versions Windows de Claude,
ChatGPT, Photoshop et les applications WPF ne sont toujours pas garanties.

Validation : tests du lanceur avec/sans terminal et chemins contenant des
espaces, tests PE des menus et de l'aller-retour des profils, parseur borné et
Clippy. La mise à jour remplace le bureau et le runtime, sans noyau/modules.
Redémarrer après installation pour charger ce nouveau bureau.
