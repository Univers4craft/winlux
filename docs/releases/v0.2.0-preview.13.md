# Winlux v0.2.0-preview.13 — Navigateurs hors ligne

- Catalogue de paquets Linux officiels Edge, Google Chrome et Firefox dans
  l’image système. Le téléchargement est effectué pendant la construction,
  avec contrôle SHA-256 contre l’index HTTPS du fournisseur.
- Installation d’Edge au premier démarrage, avant le bureau ; Edge est le
  navigateur par défaut tant qu’un autre choix n’a pas été enregistré.
- Nouvelle page **Paramètres > Navigateurs** : installer, choisir par défaut
  et ouvrir chacun des trois navigateurs. Choisir installe le navigateur au
  besoin, depuis le paquet local, sans connexion.
- Si aucun navigateur utilisable n’est installé, le bouton Navigateur ouvre
  cette page. Un échec de lancement demande également de consulter ce choix.
- Profils séparés dans `/home/winlux-web`, exécution sous un compte dédié et
  sandbox conservée. Les paquets sont extraits dans `/opt/winlux/browsers` ;
  Winlux n’utilise pas de base APT et n’exécute pas leurs scripts Debian.
- Outils d’extraction complets et bibliothèques Linux intégrés à l’image.
  Le catalogue augmente la taille du téléchargement système.

Une mise à jour système puis un redémarrage sont nécessaires pour bénéficier
du nouveau bureau, des bibliothèques et de l’installation automatique d’Edge.
Les profils existants des navigateurs restent conservés.

Validation : choix du navigateur, intégrité des archives et échecs d’installation
testés avec des paquets isolés, y compris sous BusyBox. Dans une VM KVM jetable,
les trois vrais navigateurs ont installé leurs paquets locaux puis rendu une
page HTML en mode headless avec leur sandbox activée. Ce test ne mesure pas
la fluidité d’une session Web complète ni la lecture vidéo.
