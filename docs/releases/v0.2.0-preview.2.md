# Winlux v0.2.0-preview.2 — préversion système expérimentale

Cette release distribue le système complet, pas seulement le runtime. Le
manifeste indique `scope=system` et le numéro affiché par Winlux provient du
même fichier `VERSION` que le paquet et l'ISO.

## Changements

- Intègre les derniers commits Win32 et graphiques de master.
- Résout le conflit des Paramètres : commandes Linux/Windows et mise à jour
  réelles, panneau Mica et accents conservés ; pas de faux numéro Windows.
- Corrige l'export provisoire GDI qui remplaçait `DeleteObject` et faisait
  échouer la suite graphique.
- Rétablit les permissions exécutables des scripts réseau et système.
- Vérifie que la version du stage ISO correspond au paquet système publié.
- Empêche le workflow runtime d'écraser les préversions système complètes.

## Installation

Validation locale : 84 tests unitaires réussis (1 test XKB ignoré sans serveur
X), dix exécutables PE en séquentiel et en parallèle, tests réseau/paramètres/
mise à jour-restauration et démarrages QEMU BIOS/UEFI réussis.

Dans la VM existante : Paramètres → Mises à jour → Rechercher, vérifier
`v0.2.0-preview.2` et la portée système, puis Tout installer. Redémarrer lorsque
l'outil le demande. Les données et la configuration dans `/etc`, dont le jeton
GitHub du dépôt privé, sont conservées. Le bouton Restaurer permet le retour
à la sauvegarde précédente.

L'ISO et le paquet ne contiennent aucun jeton. L'ISO est une image Live de
test ; l'installation autonome sur un disque physique n'est pas fournie.
L'environnement reste expérimental, sans garantie de compatibilité avec tous
les exécutables Windows, .NET graphique ou Photoshop.

Le canal `/releases/latest` ne lit pas les commits et exclut les releases
marquées prerelease : cette préversion est donc publiée comme dernière release
ordinaire, tout en conservant son nom et ses avertissements expérimentaux.
