# Winlux v0.2.0-preview.3 — détails des mises à jour

## Ce qui change dans la page Mises à jour

- Le panneau inférieur affiche maintenant les modifications détaillées de
  la version proposée, et pas uniquement les noms des composants techniques.
- Les notes sont récupérées depuis la release GitHub lors de Rechercher,
  y compris lorsque le dépôt est privé et utilise votre jeton enregistré.
- Chaque fichier de notes est associé au manifeste par une somme SHA-256.
  Une note altérée, trop volumineuse ou incohérente est refusée.
- Les notes restent consultables hors ligne après une recherche réussie.
  Elles sont toujours rattachées au numéro de version correspondant.
- Les paragraphes longs reviennent automatiquement à la ligne au lieu
  d'être coupés à droite. Les accents français sont conservés.
- La molette et les touches Haut/Bas permettent de défiler ; Page précédente
  et Page suivante avancent plus vite ; Début/Fin rejoignent les extrémités.
- Le bouton Afficher le journal garde les messages techniques d'installation
  séparés du descriptif des modifications. Voir les modifications y revient.
- Une ancienne release sans notes affiche une explication, sans inventer
  de liste de nouveautés ni empêcher l'utilisation de son paquet.

## Également inclus si vous venez de preview.1

- Les derniers ajouts Win32 et graphiques de master sont embarqués.
- Les Paramètres réunissent les commandes Linux/Windows réelles, le panneau
  Mica et les accents visuels, sans faux numéro de version Windows.
- L'export DeleteObject fonctionne à nouveau : un stub de région ne remplace
  plus la libération réelle des objets graphiques et la protection des
  pinceaux système.
- Les scripts système et réseau ont retrouvé leurs permissions exécutables.
- Le fichier VERSION fournit le même numéro à l'ISO et au paquet système.
  Un paquet dont le numéro ne correspond pas au stage ISO est refusé.
- Le workflow runtime ne remplace plus une préversion système complète par
  un paquet réduit lors de la publication de son tag.

## Installation et données conservées

Cette mise à jour contient le système complet : bureau, runtime Win32,
outils de mise à jour, applications embarquées, noyau, pilotes et bibliothèques.
Installer via Tout installer puis redémarrer quand l'outil le demande.
Les fichiers personnels et les réglages /etc, dont la clé GitHub, sont
conservés. Restaurer permet de revenir à la sauvegarde de la mise à jour.

Le nouvel affichage apparaît après installation de cette version : l'ancien
programme de preview.1/2 ne sait pas encore afficher ces notes détaillées.
L'ISO et le code GitHub ne contiennent aucun jeton privé.

## Limites connues

Winlux reste une préversion expérimentale, pas un remplacement Windows
complet. La compatibilité universelle des .exe, .NET graphique et Photoshop
n'est pas garantie. L'ISO reste une image Live de test sans installateur
autonome pour disque physique. Les mises à jour ne sont pas encore signées
et ne disposent pas de partitions A/B contre les coupures d'alimentation.
