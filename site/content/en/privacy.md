## This website

This website uses no cookies, no analytics and no fonts or scripts from another site. The host, GitHub, receives your IP address and browser like for any web page. The download buttons query the GitHub API from your browser to find the latest version.

## The system

The system sends no usage statistics and contains no telemetry. It only connects to the Internet for these services:

| Service | Recipient | What is sent | When |
|---|---|---|---|
| System updates | GitHub | IP address, installed version | automatic check |
| Applications and packages | Ubuntu archives and application publishers | IP address, requested packages | when you install or update an application |
| Widget weather | the wttr.in service | IP address, chosen place | only after you agree, off by default |
| Report a problem | GitHub (public issue) | the report, which you review before sending | only when you send it |
| Online AI assistants | the publisher of the chosen assistant, with your own account | your questions and what you choose to show | only if you turn an assistant on, all off by default |
| Local AI | nobody | nothing leaves the PC | — |
| Phone link | your phone, on the local network | the data you exchange | only if you pair it |

For online AI assistants, the terms and privacy policy of their publisher apply to your account. The project itself sees, keeps and forwards nothing.

## Your rights

The project receives no personal data from people using the system. For any question: [open an issue on GitHub](https://github.com/Univers4craft/winlux/issues).
