## Report a problem

The most useful way to move Winlux forward is to tell us what does not work.

- **After a crash**, Winlux opens the “Report a problem” window with the probable cause already filled in.
- **At any time**, open **Settings › Report a problem** to describe an issue.

The full report is shown before sending, and you can edit it. Personal data (file names, paths, identifiers, Wi-Fi networks) is masked by default. The report opens in your browser on the project's [reported issues](https://github.com/Univers4craft/winlux/issues) page; a free GitHub account is needed to submit it. Nothing is ever sent without your action.

![The Report a problem page](img:signaler-un-probleme.jpg "Settings › Report a problem: new report, last crash and settings.")

## The PC no longer starts

In the boot menu, choose **“Winlux secours”** (key `s`), or **“Winlux Recovery”** from the USB drive (key `r`). It offers to repair startup, restore the previous restore point, check the disk or open a rescue terminal.

## Frequently asked questions

### Is it Windows?

No. Winlux is a complete Linux system. It can open Windows programs thanks to a compatibility layer written for it, but it contains no Windows component and requires no Windows licence.

### Do I need an online account?

No. Accounts are local, and Winlux sends no usage data.

### Will my games work?

Some simple games, yes. Recent Direct3D 11 or 12 games and games protected by system-level anti-cheat do not work yet. See [Tested applications](page:apps).

### Can I keep Windows alongside?

Yes: the installer can shrink the Windows partition and add a menu to choose the system at startup. See [Install Winlux](page:guide-install#choose-where-to-install).

### Where can I find more details?

The [technical wiki](wiki:FAQ) (in French) answers more specific questions, and honestly lists the [known limitations](wiki:Limites-et-problemes-connus).
