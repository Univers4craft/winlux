The Winlux desktop uses the common keyboard shortcuts, with the Windows key. They work in every application, Windows programs included.

## Keyboard shortcuts

| Shortcut | What it does |
|---|---|
| Windows + ← / → / ↑ / ↓ | Snaps the window to half or a quarter of the screen, maximises it or restores its size |
| Windows + Z | Snap layouts (also by right-clicking the Maximise button) |
| Windows + Tab | Task view: all windows and virtual desktops |
| Windows + Ctrl + D / F4 | New virtual desktop, close the virtual desktop |
| Windows + H / Windows + Ctrl + L | Voice typing into the active text box, live captions of the PC's audio (recognised on this PC, nothing is sent) |
| Windows + V | Clipboard history |
| Windows + . | Emoji, kaomoji and symbols |
| Windows + Shift + C | Colour picker: copy the code of a colour on screen |
| Windows + Shift + T | Copy the text of an area of the screen |
| Windows + Ctrl + T | Keep the window always on top |
| Windows + A | Quick settings (Wi-Fi, sound, night light) |
| Windows + W | Widgets |

## Windows and desktops

After you snap a window to half of the screen, Snap Assist offers your other windows to fill the other half. Windows + Tab also shows your virtual desktops: create one per activity, rename them, and drag a window from one to another.

## Clipboard, emoji and text

Windows + V keeps the last 25 texts and images you copied; pin the ones you reuse often. Windows + Shift + T freezes the screen: draw a box around some text, even in a picture or a paused video, and it is copied. Text recognition is downloaded on first use, in French, English, Spanish and German.

> [!tip]
> In the image viewer, the “Copy text” button does the same for a photo or a scanned document.

## Clock, night light and theme

The Clock app in the Start menu brings together alarms, timers, the stopwatch, world clocks and focus sessions. Night light warms the colours in the evening, and the “Automatic” colour mode switches to light by day and dark in the evening. The wallpaper can also change as a slideshow.

## Rename several files

Select several files in Explorer, then right-click › Rename multiple files. Search and replace, numbering, changing the case: the preview shows every new name before you confirm, and the last rename can be undone.
