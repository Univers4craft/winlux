## Diese Website

Diese Website verwendet keine Cookies, keine Statistikwerkzeuge und keine Schriften oder Skripte anderer Websites. Der Hoster GitHub erhält wie bei jeder Webseite Ihre IP-Adresse und Ihren Browser. Die Download-Schaltflächen fragen aus Ihrem Browser die GitHub-API nach der neuesten Version.

## Das System

Das System sendet keine Nutzungsstatistiken und enthält keine Telemetrie. Es verbindet sich nur für diese Dienste mit dem Internet:

| Dienst | Empfänger | Was gesendet wird | Wann |
|---|---|---|---|
| Systemupdates | GitHub | IP-Adresse, installierte Version | automatische Prüfung |
| Anwendungen und Pakete | Ubuntu-Archive und Herausgeber der Anwendungen | IP-Adresse, angeforderte Pakete | wenn Sie eine Anwendung installieren oder aktualisieren |
| Wetter der Widgets | der Dienst wttr.in | IP-Adresse, gewählter Ort | nur nach Ihrer Zustimmung, standardmäßig aus |
| Problem melden | GitHub (öffentliches Issue) | der Bericht, den Sie vor dem Senden lesen | nur wenn Sie ihn senden |
| Online-KI-Assistenten | der Herausgeber des gewählten Assistenten, mit Ihrem eigenen Konto | Ihre Fragen und was Sie zeigen möchten | nur wenn Sie einen Assistenten aktivieren, standardmäßig alle aus |
| Lokale KI | niemand | nichts verlässt den PC | — |
| Smartphone-Verbindung | Ihr Telefon, im lokalen Netzwerk | die ausgetauschten Daten | nur wenn Sie es koppeln |

Für Online-KI-Assistenten gelten für Ihr Konto die Bedingungen und die Datenschutzerklärung ihres Herausgebers. Das Projekt selbst sieht, speichert und übermittelt nichts.

## Ihre Rechte

Das Projekt erhält keine personenbezogenen Daten von den Nutzern des Systems. Bei Fragen: [ein Issue auf GitHub eröffnen](https://github.com/Univers4craft/winlux/issues).
