## Einfach doppelklicken

Doppelklicken Sie im Explorer oder auf dem Desktop auf eine `.exe`-Datei: Sie öffnet sich direkt. Vorher muss nichts installiert oder eingerichtet werden.

![Die Winlux-Tour: ein Windows-Programm starten](img:lancer-un-exe.jpg "Die Tour beim ersten Start zeigt, wie man ein Windows-Programm startet.")

## Software installieren

1. Laden Sie das Installationsprogramm von der Website des Herstellers herunter (`setup.exe`, `installer.exe` oder `.msi`).
2. Doppelklicken Sie darauf und folgen Sie den Schritten seines Installationsprogramms.
3. Die Software erscheint im Startmenü. Zum Entfernen öffnen Sie **Installierte Apps**.

Die gängigsten Installationsprogramme (MSI, NSIS, Inno Setup) werden unterstützt. Der **Store** von Winlux bietet außerdem Windows- und Linux-Software zur Installation mit einem Klick.

## Berechtigungen

Wenn ein Programm zum ersten Mal **Kamera**, **Mikrofon**, **Bildschirmaufnahme** oder Ihre **persönlichen Ordner** verwenden möchte, fragt Winlux nach Ihrer Zustimmung. Sie können Ihre Entscheidung jederzeit unter Einstellungen › Datenschutz und Sicherheit ändern, wo sich auch der Netzwerkzugriff für einzelne Programme sperren lässt.

Wenn ein Installationsprogramm Administratorrechte verlangt, öffnet Winlux ein Bestätigungsfenster.

## Wenn ein Programm sich nicht öffnet

| Meldung | Was sie bedeutet |
|---|---|
| „32-Bit-Windows-Programm“ | Derzeit werden nur 64-Bit-Programme unterstützt. Suchen Sie die 64-Bit-Version der Software. |
| „Fehlende Funktion“ | Das Programm nutzt eine Windows-Funktion, die Winlux noch nicht bereitstellt. Melden Sie es: Genau das sagt uns, was wir als Nächstes schreiben. |
| Das Programm schließt sich kommentarlos | Öffnen Sie die Ereignisanzeige über das Startmenü: Dort ist die Ursache vermerkt. |

Nach einem Absturz bietet Winlux an, **das Problem zu melden**: siehe [Hilfe erhalten](page:guide-help). Die Liste der bereits ausprobierten Software steht auf der Seite [Getestete Anwendungen](page:apps).
