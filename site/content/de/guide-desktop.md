Der Winlux-Desktop nutzt die gängigen Tastenkombinationen mit der Windows-Taste. Sie funktionieren in allen Anwendungen, auch in Windows-Programmen.

## Tastenkombinationen

| Tastenkombination | Was sie bewirkt |
|---|---|
| Windows + ← / → / ↑ / ↓ | Dockt das Fenster an eine Bildschirmhälfte oder ein Viertel an, maximiert es oder stellt seine Größe wieder her |
| Windows + Z | Andocklayouts (auch per Rechtsklick auf die Schaltfläche Maximieren) |
| Windows + Tab | Aktive Anwendungen: alle Fenster und virtuellen Desktops |
| Windows + Strg + D / F4 | Neuer virtueller Desktop, virtuellen Desktop schließen |
| Windows + H | Spracheingabe in das aktive Textfeld (Erkennung auf diesem PC, nichts wird gesendet) |
| Windows + Strg + L | Liveuntertitel dessen, was aus den Lautsprechern kommt |
| Windows + V | Zwischenablageverlauf |
| Windows + . | Emojis, Kaomojis und Symbole |
| Windows + Umschalt + C | Farbwähler: den Code einer Bildschirmfarbe kopieren |
| Windows + Umschalt + T | Den Text eines Bildschirmbereichs kopieren |
| Windows + Strg + T | Fenster immer im Vordergrund halten |
| Windows + A | Schnelleinstellungen (WLAN, Ton, Nachtmodus) |
| Windows + W | Widgets |

## Fenster und Desktops

Nachdem Sie ein Fenster an eine Bildschirmhälfte angedockt haben, schlägt der Andock-Assistent Ihre anderen Fenster für die andere Hälfte vor. Windows + Tab zeigt auch Ihre virtuellen Desktops: Legen Sie einen pro Tätigkeit an, benennen Sie sie um und ziehen Sie ein Fenster von einem zum anderen.

## Zwischenablage, Emojis und Text

Windows + V behält die letzten 25 kopierten Texte und Bilder; heften Sie die an, die Sie oft wiederverwenden. Windows + Umschalt + T friert den Bildschirm ein: Ziehen Sie einen Rahmen um einen Text, auch in einem Bild oder einem angehaltenen Video, und er wird kopiert. Die Texterkennung wird bei der ersten Verwendung heruntergeladen, auf Französisch, Englisch, Spanisch und Deutsch.

> [!tip]
> In der Bildanzeige macht die Schaltfläche „Text kopieren“ dasselbe für ein Foto oder ein gescanntes Dokument.

## Uhr, Nachtmodus und Design

Die App Uhr im Startmenü vereint Wecker, Timer, Stoppuhr, Weltuhr und Fokussitzungen. Der Nachtmodus macht die Farben abends wärmer, und der Farbmodus „Automatisch“ wechselt tagsüber zu hell und abends zu dunkel. Der Hintergrund kann auch als Diashow wechseln.

## Mehrere Dateien umbenennen

Wählen Sie im Explorer mehrere Dateien aus, dann Rechtsklick › Mehrere Dateien umbenennen. Suchen und ersetzen, nummerieren, Groß- und Kleinschreibung ändern: Die Vorschau zeigt jeden neuen Namen vor dem Bestätigen, und das letzte Umbenennen lässt sich rückgängig machen.
