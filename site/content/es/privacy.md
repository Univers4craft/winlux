## Este sitio

Este sitio no usa cookies, ni herramientas de estadísticas, ni fuentes o scripts de otros sitios. El alojamiento, GitHub, recibe como en cualquier página web su dirección IP y el navegador usado. Los botones de descarga consultan la API de GitHub desde su navegador para conocer la última versión.

## El sistema

El sistema no envía estadísticas de uso y no contiene telemetría. Solo se conecta a Internet para estos servicios:

| Servicio | Destinatario | Lo que se envía | Cuándo |
|---|---|---|---|
| Actualizaciones del sistema | GitHub | dirección IP, versión instalada | comprobación automática |
| Aplicaciones y paquetes | repositorios de Ubuntu y editores de las aplicaciones | dirección IP, paquetes pedidos | cuando instala o actualiza una aplicación |
| Tiempo de los widgets | el servicio wttr.in | dirección IP, lugar elegido | solo tras su consentimiento, desactivado de forma predeterminada |
| Informar de un problema | GitHub (incidencia pública) | el informe, que usted revisa antes del envío | solo cuando lo envía |
| Asistentes de IA en línea | el editor del asistente elegido, con su propia cuenta | sus preguntas y lo que decide mostrar | solo si activa un asistente, todos desactivados de forma predeterminada |
| IA local | nadie | nada sale del PC | — |
| Vínculo con el teléfono | su teléfono, en la red local | los datos intercambiados | solo si lo empareja |

Para los asistentes de IA en línea, se aplican a su cuenta las condiciones y la política de privacidad de su editor. El proyecto no ve, no guarda ni transmite nada por sí mismo.

## Sus derechos

El proyecto no recibe ningún dato personal de quienes usan el sistema. Para cualquier pregunta: [abrir una incidencia en GitHub](https://github.com/Univers4craft/winlux/issues).
