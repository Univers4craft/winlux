El escritorio de Winlux usa los atajos de teclado habituales, con la tecla Windows. Funcionan en todas las aplicaciones, incluidos los programas de Windows.

## Atajos de teclado

| Atajo | Qué hace |
|---|---|
| Windows + ← / → / ↑ / ↓ | Acopla la ventana a la mitad o a un cuarto de la pantalla, la maximiza o le devuelve su tamaño |
| Windows + Z | Diseños de acoplamiento (también con clic derecho en el botón Maximizar) |
| Windows + Tab | Vista de tareas: todas las ventanas y los escritorios virtuales |
| Windows + Ctrl + D / F4 | Nuevo escritorio virtual, cerrar el escritorio virtual |
| Windows + H | Dictado por voz en el cuadro de texto activo (reconocimiento en este PC, no se envía nada) |
| Windows + Ctrl + L | Subtítulos en directo de lo que sale por los altavoces |
| Windows + V | Historial del portapapeles |
| Windows + . | Emojis, kaomojis y símbolos |
| Windows + Mayús + C | Selector de colores: copiar el código de un color de la pantalla |
| Windows + Mayús + T | Copiar el texto de una zona de la pantalla |
| Windows + Ctrl + T | Mantener la ventana siempre visible |
| Windows + A | Configuración rápida (Wi-Fi, sonido, luz nocturna) |
| Windows + W | Widgets |

## Ventanas y escritorios

Después de acoplar una ventana a la mitad de la pantalla, el Asistente para acoplar le propone sus otras ventanas para llenar la otra mitad. Windows + Tab también muestra sus escritorios virtuales: cree uno por actividad, cámbieles el nombre y arrastre una ventana de uno a otro.

## Portapapeles, emojis y texto

Windows + V guarda los últimos 25 textos e imágenes copiados; ancle los que reutiliza a menudo. Windows + Mayús + T congela la pantalla: enmarque un texto, incluso en una imagen o un vídeo en pausa, y se copia. El reconocimiento de texto se descarga en el primer uso, en francés, inglés, español y alemán.

> [!tip]
> En el visor de imágenes, el botón «Copiar texto» hace lo mismo con una foto o un documento escaneado.

## Reloj, luz nocturna y tema

La aplicación Reloj del menú Inicio reúne las alarmas, los temporizadores, el cronómetro, el reloj mundial y las sesiones de concentración. La luz nocturna calienta los colores por la noche, y el modo de color «Automático» pasa a claro de día y a oscuro por la noche. El fondo de pantalla también puede cambiar como una presentación.

## Cambiar el nombre de varios archivos

Seleccione varios archivos en el Explorador y luego clic derecho › Cambiar el nombre de varios archivos. Buscar y reemplazar, numerar, cambiar mayúsculas y minúsculas: la vista previa muestra cada nuevo nombre antes de confirmar, y el último cambio de nombre se puede deshacer.
