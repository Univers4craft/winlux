## Ce site

Ce site n'utilise ni cookie, ni outil de statistiques, ni police ou script venant d'un autre site. L'hébergeur, GitHub, reçoit comme pour toute page web votre adresse IP et le navigateur utilisé. Les boutons de téléchargement interrogent l'API de GitHub depuis votre navigateur pour connaître la dernière version.

## Le système

Le système n'envoie aucune statistique d'utilisation et ne contient aucune télémétrie. Il ne se connecte à Internet que pour les services suivants :

| Service | Destinataire | Ce qui part | Quand |
|---|---|---|---|
| Mises à jour du système | GitHub | adresse IP, version installée | vérification automatique |
| Applications et paquets | dépôts Ubuntu et éditeurs des applications | adresse IP, paquets demandés | quand vous installez ou mettez à jour une application |
| Météo des widgets | service wttr.in | adresse IP, lieu choisi | seulement après votre accord, désactivée par défaut |
| Signaler un problème | GitHub (issue publique) | le rapport, que vous relisez avant l'envoi | seulement quand vous l'envoyez |
| Assistants d'IA en ligne | l'éditeur de l'assistant choisi, avec votre propre compte | vos questions et ce que vous choisissez de montrer | seulement si vous activez un assistant, désactivés par défaut |
| IA locale | personne | rien ne quitte le PC | — |
| Lien avec le téléphone | votre téléphone, sur le réseau local | les données échangées | seulement si vous l'associez |

Pour les assistants d'IA en ligne, ce sont les conditions et la politique de confidentialité de leur éditeur qui s'appliquent à votre compte. Le projet ne voit, ne garde et ne transmet rien lui-même.

## Vos droits

Le projet ne reçoit aucune donnée personnelle des utilisateurs du système. Pour une question : [ouvrir une issue sur GitHub](https://github.com/Univers4craft/winlux/issues).
