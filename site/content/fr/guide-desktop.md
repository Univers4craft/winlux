Le bureau de Winlux utilise les raccourcis clavier courants, avec la touche Windows. Ils marchent dans toutes les applications, programmes Windows compris.

## Raccourcis clavier

| Raccourci | Ce qu'il fait |
|---|---|
| Windows + ← / → / ↑ / ↓ | Ancre la fenêtre sur une moitié ou un quart de l'écran, l'agrandit ou lui rend sa taille |
| Windows + Z | Dispositions d'ancrage (aussi au clic droit sur le bouton Agrandir) |
| Windows + Tab | Vue des tâches : toutes les fenêtres et les bureaux virtuels |
| Windows + Ctrl + D / F4 | Nouveau bureau virtuel, fermer le bureau virtuel |
| Windows + H | Dictée vocale dans la zone de texte active (reconnaissance sur ce PC, rien n'est envoyé) |
| Windows + Ctrl + L | Sous-titres en direct de ce qui sort des haut-parleurs |
| Windows + V | Historique du presse-papiers |
| Windows + . | Emojis, kaomojis et symboles |
| Windows + Maj + C | Pipette : copier le code d'une couleur de l'écran |
| Windows + Maj + T | Copier le texte d'une zone de l'écran |
| Windows + Ctrl + T | Garder la fenêtre au premier plan |
| Windows + A | Réglages rapides (Wi-Fi, son, éclairage nocturne) |
| Windows + W | Widgets |

## Fenêtres et bureaux

Après un ancrage sur une moitié de l'écran, l'Assistant d'ancrage propose vos autres fenêtres pour remplir l'autre moitié. Windows + Tab montre aussi vos bureaux virtuels : créez-en un par activité, renommez-les, et glissez une fenêtre de l'un à l'autre.

## Presse-papiers, emojis et texte

Windows + V garde les 25 derniers textes et images copiés ; épinglez ceux que vous réutilisez souvent. Windows + Maj + T fige l'écran : encadrez un texte, même dans une image ou une vidéo en pause, et il est copié. La reconnaissance de texte se télécharge au premier usage, en français, anglais, espagnol et allemand.

> [!tip]
> Dans la visionneuse d'images, le bouton « Copier le texte » fait la même chose pour une photo ou un document scanné.

## Horloge, éclairage nocturne et thème

L'application Horloge du menu Démarrer regroupe les alarmes, les minuteurs, le chronomètre, les horloges du monde et les sessions de concentration. L'éclairage nocturne réchauffe les couleurs le soir, et le mode de couleur « Automatique » passe en clair le jour et en sombre le soir. Le fond d'écran peut aussi défiler en diaporama.

## Renommer plusieurs fichiers

Sélectionnez plusieurs fichiers dans l'Explorateur, puis clic droit › Renommer plusieurs fichiers. Rechercher et remplacer, numéroter, changer la casse : l'aperçu montre chaque nouveau nom avant de valider, et le dernier renommage peut être annulé.
